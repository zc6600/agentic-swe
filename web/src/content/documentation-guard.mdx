# Documentation Guard

Checks Markdown length and adds actionable annotations to failed GitHub Actions runs. Default limits: 2,000 words for `README.md`, 4,000 for other `.md` and `.mdx` files. Both are configurable.

**For maintainers:** Add one step to CI. No secrets are needed; limits are optional.

<details id="maintainer-setup">
<summary>Maintainer setup</summary>

Add this step to an existing GitHub Actions job:

```yaml
- name: Documentation Guard
  uses: zc6600/agentic-swe@main
  with:
    readme-limit: 2000   # optional, words
    doc-limit: 4000      # optional, words
```
